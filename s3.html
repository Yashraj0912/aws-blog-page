Object Storage Amazon Web Services

Amazon S3

Simple Storage Service — Store and retrieve any amount of data, at any time, from anywhere on the web. Highly scalable, durable, and secure object storage.

📖 What is Amazon S3?

Amazon Simple Storage Service (Amazon S3) is an object storage service offering industry-leading scalability, data availability, security, and performance.

Data in S3 is stored in containers called "buckets" as "objects". S3 provides 99.999999999% (11 9's) of durability and enables you to store data for a range of use cases, such as data lakes, websites, mobile applications, backup and restore, archive, enterprise applications, IoT devices, and big data analytics.

⭐ Key Features

🛡️

11 9's of Durability

Data is redundantly stored across multiple facilities and devices in an AWS Region.

📂

Storage Classes

S3 Standard, Intelligent-Tiering, Glacier, etc. Optimize for cost based on access frequency.

🔒

Robust Security

Block public access, enforce IAM policies, encrypt data at rest, and use AWS KMS seamlessly.

📈

Infinite Scale

Virtually unlimited storage capacity. No need to provision storage upfront.

🌐

Static Web Hosting

Host simple static websites directly from an S3 bucket with minimal configuration.

⚙️

Lifecycle Management

Automatically move older data to cheaper storage classes like Glacier to reduce costs.

🚀 Common Use Cases

1

Backup and Restore

Backup massive quantities of data securely to S3, taking advantage of its durability.

2

Data Lakes

S3 is the central storage for AWS data lakes, holding petabytes of structured and unstructured data.

3

Static Website Hosting

Deploy HTML, CSS, JavaScript, and image files without provisioning any web servers.
