High-Performance Relational Amazon Web Services

Amazon Aurora

A MySQL and PostgreSQL-compatible relational database built for the cloud, that combines the performance and availability of traditional enterprise databases with the simplicity and cost-effectiveness of open source databases.

📖 What is Amazon Aurora?

Amazon Aurora is a fully managed relational database engine that's compatible with MySQL and PostgreSQL. You already know how to build for MySQL or PostgreSQL, and you can use your existing code, tools, and applications with Aurora.

Aurora is up to five times faster than standard MySQL databases and three times faster than standard PostgreSQL databases. It features a distributed, fault-tolerant, self-healing storage system that auto-scales up to 128TB per database instance.

⭐ Key Features

🚀

High Performance

Up to 5x throughput of standard MySQL and 3x throughput of standard PostgreSQL.

🔄

Auto-Scaling Storage

Storage grows automatically as your database grows, with no downtime or performance impact.

🛡️

High Availability

Data is replicated across multiple Availability Zones, with automatic failover in case of a component failure.

🚫

Aurora Serverless

An on-demand, auto-scaling configuration where the database automatically starts up, shuts down, and scales capacity up or down based on your application's needs.
