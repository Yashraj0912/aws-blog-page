Compute Services

AWS Compute services let you run applications without managing physical hardware. From virtual machines to serverless functions and containers — pick the right compute model for your workload.

🔍
💻

Amazon EC2

Elastic Compute Cloud — Launch virtual servers (instances) in the cloud in minutes. Choose CPU, memory, storage, and networking capacity as needed.

Virtual Servers

AWS Lambda

Run code without provisioning or managing servers. Lambda automatically scales your application and charges only for the compute time you consume.

Serverless
🐳

Amazon ECS / EKS

Run Docker containers at scale with Elastic Container Service (ECS), or use Elastic Kubernetes Service (EKS) for managed Kubernetes orchestration.

Deploy and manage web applications without worrying about the infrastructure. Upload your code and Beanstalk handles deployment, capacity, and monitoring.
