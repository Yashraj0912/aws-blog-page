Amazon RDS

Relational Database Service — Set up, operate, and scale relational databases easily in the cloud. Focus on your application while AWS manages the database administration overhead.

📖 What is Amazon RDS?

Amazon Relational Database Service (Amazon RDS) makes it easy to set up, operate, and scale a relational database in the cloud. It provides cost-efficient and resizable capacity while automating time-consuming administration tasks such as hardware provisioning, database setup, patching, and backups.

It frees you to focus on your applications, not the database operations. You can choose from multiple well-known database engines including Amazon Aurora, PostgreSQL, MySQL, MariaDB, Oracle Database, and SQL Server.

⭐ Key Features

🛡️

Automated Backups

RDS handles automated backups and snapshots that allow point-in-time recovery during the retention period.

🔄

Multi-AZ Deployments

High availability with automatic failover to a synchronous standby replica in a different Availability Zone.

📈

Read Replicas

Scale out easily by creating one or more read replicas to serve high-volume application read traffic.

⚙️

Managed Patching

AWS automatically applies the latest security patches to the underlying OS and Database Engine.

🚀 Common Use Cases

1

Web and Mobile Apps

RDS is a staple backend for applications requiring structured relational data with strong ACID guarantees.

2

Enterprise Applications

Lift-and-shift legacy on-premises Oracle and SQL Server systems to the cloud.
