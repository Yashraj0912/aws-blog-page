AWS Shield

Managed Distributed Denial of Service (DDoS) protection service that safeguards applications running on AWS.

📖 What is AWS Shield?

AWS Shield is a managed Distributed Denial of Service (DDoS) protection service that safeguards applications running on AWS. AWS Shield provides always-on detection and automatic inline mitigations that minimize application downtime and latency.

There are two tiers: Standard and Advanced. All AWS customers benefit from the automatic protections of AWS Shield Standard at no additional charge.

⭐ Key Features

🛡️

Standard Tier

Free, fast, always-on automatic inline mitigation protecting from most common infrastructure-level attacks.

🚨

Advanced Tier

Additional protections against larger HTTP floods and direct access to the DDoS Response Team (DRT).

💰

Cost Protection

(Advanced tier) Protection against scaling cost spikes that result from DDoS attacks escalating auto-scaling instances.

👁️

Deep Observability

Real-time metrics and reports surrounding the nature and history of attempted network attacks.

🚀 Common Use Cases

1

Public Web Applications

Ensure an e-commerce platform stays available during sudden large and malicious traffic spikes globally.

2

Gaming Backends

Stop sudden large volumetric UDP bursts aimed at taking multiplayer servers offline.
