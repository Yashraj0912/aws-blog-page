Amazon EBS

Elastic Block Store (EBS) — High-performance block storage designed for use with Amazon EC2 for both throughput and transaction-intensive workloads.

📖 What is Amazon EBS?

Amazon Elastic Block Store (Amazon EBS) provides block level storage volumes for use with EC2 instances. EBS volumes behave like raw, unformatted block devices. You can mount these volumes as devices on your instances.

EBS volumes are particularly suited for use cases that require a database, a file system, or access to raw block-level storage. You can create multiple volumes and attach them to any of your EC2 instances.

⭐ Key Features

🚀

Performance

Choose between SSD-backed volumes for transactional workloads and HDD-backed volumes for throughput-intensive workloads.

🛡️

Availability

Volumes are automatically replicated within their Availability Zone to protect you from component failure.

🔒

Encryption

EBS encryption offers seamless encryption of data at rest, data in transit, and snapshots.

📸

Snapshots

Back up your data by taking point-in-time snapshots of your volumes, which are stored in Amazon S3.
