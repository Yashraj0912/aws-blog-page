Amazon EFS

Elastic File System (EFS) — Simple, serverless, set-and-forget elastic file system for use with AWS Cloud services and on-premises resources.

📖 What is Amazon EFS?

Amazon Elastic File System (Amazon EFS) provides a simple, serverless, set-and-forget elastic file system. It is built to scale on demand to petabytes without disrupting applications, growing and shrinking automatically as you add and remove files.

EFS supports the Network File System version 4 (NFSv4.1 and NFSv4.0) protocol, so the applications and tools that you use today work seamlessly with Amazon EFS. Multiple EC2 instances can access an Amazon EFS file system at the same time.

⭐ Key Features

📉

Dynamic Elasticity

Automatically grows and shrinks as you add or remove files, so you don't need to provision storage.

🔄

Shared Storage

Multiple EC2 instances, Lambda functions, and containers can mount an EFS file system simultaneously.

🚀

High Availability

EFS is designed to be highly available and durable, storing data across multiple Availability Zones.

🛡️

Fully Managed

AWS handles the underlying infrastructure, including provisioning, patching, and backups.
