Database Services

Choose from a broad selection of purpose-built database engines — relational, NoSQL, in-memory, and data warehouse — managed, scalable, and optimized for different use cases.

🔍
🐘

Amazon RDS

Relational Database Service — Set up, operate, and scale relational databases easily. Supports MySQL, PostgreSQL, MariaDB, Oracle, and SQL Server.

Relational
⚡

Amazon DynamoDB

A fully managed, serverless NoSQL key-value and document database. Delivers single-digit millisecond performance at any scale — no server management needed.

NoSQL
🌠

Amazon Aurora

A MySQL and PostgreSQL-compatible relational database built for the cloud. Combines the performance of high-end commercial databases with open-source simplicity.

High Perf Relational
📦

Amazon Redshift

A fast, fully managed cloud data warehouse. Analyze petabytes of data using standard SQL and your existing Business Intelligence tools — at a fraction of traditional costs.

Data Warehouse
